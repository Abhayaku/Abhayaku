## 🚀 What I Build

### 🤖 Conversational AI & Voice Agents

Building real-time AI-powered conversational systems for interactive training, simulations, and intelligent user experiences.

- Real-time **STT → LLM → TTS** pipelines.
- Streaming LLM responses and low-latency audio generation.
- Voice Activity Detection (VAD) and turn management.
- Scenario-based AI conversations with state management.
- Automated conversation analysis, evaluation, and feedback.
- Integration with OpenAI, Google Chirp, ElevenLabs, and LiveKit.

### 📱 High-Performance Mobile Applications

Developing production-grade React Native applications with native capabilities and polished user experiences.

- Cross-platform iOS and Android development.
- Complex animations using Reanimated and Gesture Handler.
- Video streaming, HLS playback, and offline caching.
- Native modules and platform-specific integrations.
- Real-time audio, WebSockets, and background processing.
- Mobile performance and memory optimization.

### ⚙️ Scalable Backend & Distributed Systems

Designing maintainable backend architectures that support real-world workloads.

- REST APIs, authentication, RBAC, and secure integrations.
- Redis caching, BullMQ, and asynchronous job processing.
- Event-driven architectures and real-time communication.
- MongoDB data modeling, aggregation, and query optimization.
- Background workers, scheduled jobs, and batch processing.
- API performance, concurrency, and fault tolerance.

### ☁️ Cloud Infrastructure & Production Reliability

Building and operating cloud-native applications with a focus on scalability and observability.

- Containerized services on AWS ECS and Fargate.
- Load balancing, autoscaling, and deployment pipelines.
- CloudWatch alarms, Grafana dashboards, and synthetic monitoring.
- CI/CD automation and production health checks.
- Troubleshooting latency, infrastructure failures, and bottlenecks.
- Designing resilient systems with graceful fallbacks.
